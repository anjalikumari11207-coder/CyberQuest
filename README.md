# ⚡ CyberQuest — 3D Cybersecurity Awareness Platform

> A fully offline, browser-based 3D cybersecurity awareness gaming website for students.
> Learn real-world cyber defense skills through immersive gameplay, quizzes and simulations.

---

## 🚀 How to Run (No Server Needed!)

1. **Download / Extract** the `CyberQuest` folder anywhere on your computer
2. **Open** `index.html` in any modern browser (Chrome, Edge, Firefox)
3. **Register** a new account and enter the 3D CyberCity!

> ✅ Works 100% offline — no internet, no server, no installation required.
> ✅ All progress saved locally in your browser (localStorage).

## 🛡️ Key Cybersecurity Topics Covered

1. **Password Security** — Strength, uniqueness, password managers, 2FA
2. **Phishing** — Email analysis, fake domains, urgency manipulation
3. **Social Engineering** — Overconfidence, psychological manipulation
4. **Public WiFi Risks** — Man-in-the-middle attacks, VPN usage
5. **Malware & Safe Downloads** — Official sources, file scanning, pop-up scams
6. **Social Media Privacy** — Personal info exposure, catfishing, oversharing
7. **OTP & 2FA** — Never share OTPs, SIM swapping awareness
8. **Cybercrime Reporting** — cybercrime.gov.in, helpline 1930
